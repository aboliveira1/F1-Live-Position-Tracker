      Enable live tracking

      Live car positions come from OpenF1's real-time feed, which needs an OpenF1 subscription. Replays of finished sessions are free and need nothing.

      1. Get an OpenF1 account at openf1.org.
      2. Copy .env.example to .env in the project folder.
      3. Fill in OPENF1_USERNAME and OPENF1_PASSWORD.
      4. Restart run_f1_tracker.py. It goes live automatically when a session is on.

      The tracker has stopped

      Run run_f1_tracker.py again to start it. This tab reconnects on its own.
